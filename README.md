# Exploring the Power of gRPC-Gateway for Writing RESTful Services

GNOME Asia Summit 2023, 1st–3rd December 2023

- Rajiv Ranjan Singh

## About

A comparison of REST and gRPC and why a service often needs both at once, followed by
gRPC-Gateway — the protocol buffer compiler plugin that generates a reverse-proxy
server — and the practical steps of defining services, writing the server logic, and
generating the stubs.

GNOME Asia Summit 2023 was held at St. Xavier's College, Kathmandu.
[Event page](https://events.gnome.org/event/170/)
